Zero-dependency proof for noembed
==================================

requirements.txt is empty. noembed's src/ modules import only from the
Python standard library (math, json, os, tempfile, pathlib, string,
collections, argparse, sys) plus its own internal modules (src.tokenizer,
src.tfidf, src.similarity, src.index, src.cli). No third-party package is
imported anywhere.

Reproduce this proof yourself:

  python3 -m venv /tmp/clean_env_test
  /tmp/clean_env_test/bin/pip list

Actual output (regenerate before final submission if the environment or
Python version changes):

  Package Version
  ------- -------
  pip     24.0

(pip itself ships with venv; nothing beyond it was installed, because
nothing beyond it was ever needed.)

Static import check (no third-party imports in src/):

  grep -rEn "^import |^from " src/*.py

...returns only stdlib modules and intra-project (src.*) imports -- verified
2026-08-29.

Note on Python version: this proof was generated on Python 3.12.3. The
project targets Python 3.14 per the hackathon's stated environment; nothing
in noembed uses a 3.14-only feature, so this proof is expected to hold
unchanged when re-run on 3.14 -- re-run it there before submission to be sure.
